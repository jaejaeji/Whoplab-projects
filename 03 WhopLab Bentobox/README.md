# Bento Box — Project README

## Draw It Out

Before touching any code, grab pen and paper (or Excalidraw). Draw a rectangle.
That's your bento box. Now draw lines inside it to make compartments. Some
compartments should be bigger than others, just like a real bento box has one
big rice section and several smaller sections around it.

Questions to answer on paper first:
- How many rows and columns is your box made of?
- Which compartment is the biggest? Why does it deserve more space?
- Is there one compartment that looks different from the rest (like a sauce
  cup)?

## Plan It Out

Now turn your drawing into a grid plan. This is the same idea as merging
cells in Excel — you're deciding which compartments "span" more than one
column or row.

- How many total columns and rows does your grid have?
- For each compartment, write down: how many columns does it span? How many
  rows does it span?
- What food goes in each compartment?
- What color accents which compartment? (Hint: think about what each color
  means before you assign it.)
- What does the outside of the box look like? What does the border look
  like?

Every decision you make here is one less decision you have to make while
you're coding.

## Identify Hurdles

Before you start coding, think about what's going to be hard.

- What CSS properties let one grid item span more than one column or row?
- How do you make an image fill its container without stretching or
  squishing?
- How do you make one compartment a circle instead of a rectangle?
- How do you set a background image on the page and still keep your content
  readable on top of it?

Google these before you get stuck on them. The goal is to make the hurdle
smaller by the time you actually reach it.

## Code Code Code!

Build your bento box:

1. Set up your HTML structure: one wrapper, one grid, one `div` per
   compartment.
2. Style the grid: decide your columns and rows.
3. Style each compartment: give it a border, a background, and space for an
   image.
4. Make specific compartments span more columns or rows.
5. Drop your food images in and see how the grid controls their shape.
6. Style the borders so they're bold and clearly visible. Don't be afraid of
   thickness here.

### Stretch Goals

- **Hover Effect** — make a compartment grow slightly or brighten when you
  hover over it, using `transform` or `filter`.
- **Custom Background** — swap the background photo for one of your own,
  and adjust the overlay so your box still stands out clearly.
- **Your Own Stretch Goal** — what's one more visual detail you could add?
  Research it before asking for help.
